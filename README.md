 Fibonacci, Matrix Operations, and Huffman Coding in C++

OVERVIEW: 
* This project demonstrates the implementation of core data structures and algorithms concepts in C++. It combines three key components:

- Fibonacci sequence using both recursion and memoization
- Matrix multiplication using a custom Matrix class
- Huffman coding for text compression and decompression

* The project also includes performance comparison between recursive and optimized approaches for Fibonacci.

1. Fibonacci Analysis
- Recursive implementation
- Memoization using hash map
- Performance comparison using execution time

2. Matrix Multiplication
- Custom Matrix class
- Dynamic input handling
- Matrix multiplication with validation
- Result display

3. Huffman Coding
- Frequency-based tree construction using priority queue
- Encoding and decoding of text
- Binary code assignment using tree traversal
- Memory cleanup for dynamic structures

CONCEPTS COVERED: 
- Recursion
- Dynamic Programming (Memoization)
- Greedy Algorithms (Huffman Coding)
- Object-Oriented Programming (Matrix class)
- Priority Queues (Min Heap)
- Tree Traversal
- Time Complexity Analysis

Tech Stack:
- Language: C++
- Libraries Used:
  - `<vector>`
  - `<unordered_map>`
  - `<queue>`
  - `<map>`
  - `<chrono>`

File Structure:
- main.cpp — contains implementation of Fibonacci, Matrix operations, and Huffman coding
